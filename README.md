# -Expense-Tracker-
💰 A simple yet powerful Python-based Expense Tracker with a modern GUI, built using Tkinter and SQLite. It allows users to manage daily expenses, visualize spending with charts, and export data to Excel and PDF. Perfect for learning desktop app development and building a portfolio project.
📌 Overview

A modern desktop Expense Tracker application built with Python.
It helps users manage daily expenses, visualize spending patterns, and export financial data in different formats.

This project is designed for learning desktop development and building a strong GitHub portfolio.

✨ Features
➕ Add expenses (Title, Amount, Category, Date)
🗑 Delete expenses
✏ Update selected expenses
🔍 Search expenses
📋 View data in a table (Treeview UI)
📊 Visualize spending with charts
💾 Export data to Excel
📄 Export data to PDF
🧠 SQLite database for data persistence
